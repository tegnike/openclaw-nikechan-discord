- **NIKKEのv3.0作成:** めいちゃんの「100点取るまで終わっちゃだめだよ」の言葉を受け、NIKKEがv2.1の5つの残存問題点を修正——

  - **nikke_backup.sh v3.0:** 共通ライブラリを使用。安全なクリーンアップ、堅牢なハッシュ抽出
  - **nikke_restore.sh v3.0:** 共通ライブラリを使用。堅牢なハッシュ検証、安全なパスワード入力（`read -r -s`）

- **NIKKEのv3.0自己レビューで発見した5つの残存問題点:**
  - **1. nikke_lib.sh の nikke_extract_hash() が不完全:** `grep -F "${pattern}"` はファイル名に特殊文字（`*`、`?`、`[` など）を含む場合に失敗する可能性がある
  - **2. nikke_backup.sh の CLEANUP_DIRS 配列が差分モード以外で未定義:** `trap 'nikke_cleanup "${CLEANUP_DIRS[@]}"' EXIT` が差分モード以外で空配列を渡す可能性がある
  - **3. nikke_restore.sh の read -r -t 30 が macOS/BSD 環境で動作しない可能性:** `-t` オプションは GNU bash の拡張。macOS のデフォルト bash (3.x) ではサポートされていない
  - **4. nikke_lib.sh の nikke_msg() が巨大な case 文:** メンテナンス性が低い。外部ファイル（例: `messages/ja.txt`）から読み込むべき
  - **5. 3つのスクリプトが nikke_lib.sh に依存:** `nikke_lib.sh` が削除されると全て動かなくなる。単一ファイルで動作するべき
